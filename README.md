📚 BookNook – A Small Online Library
📝 Project Description

BookNook is an online library management system where users can explore books, view book details, add new books, and manage their book collections. Users can also borrow books and track their borrowing history and return dates. It provides a simple and user-friendly way to manage books in one place.

🛠️ Technologies Used
Layer	Technologies
Frontend	Next.js, React, TypeScript, Tailwind CSS
Backend	Node.js, Express.js
Database	MongoDB
Authentication	Better Auth
UI Components	shadcn/ui
✨ Key Features
User Authentication: Secure sign-up, login, and password reset.
Book Management: Add, update, delete, and manage books.
Book Categories: Browse and explore books by category.
Borrow Books: Borrow books and manage borrowing records.
Borrowing History: Track borrowed books and their return dates.
